CYN Assistant — Android-помощница с анимированным персонажем поверх экрана и локальным ИИ Qwen2.5. Текстовый чат без API-ключа и оплаты за запросы после скачивания модели. Голосовой ввод и озвучка, память, заметки, команды телефона и загрузка своего PNG-персонажа. Написано на Kotlin и Jetpack Compose.
